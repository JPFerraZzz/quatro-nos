# quatro-nos

Projeto de grupo de Laboratório de Redes (ISPGAYA, 2026/2027): rede empresarial com 4 nós remotos e 1 nó central, desenhada e simulada no Cisco Packet Tracer.

## Equipa
- Guilherme Cruz — Project Manager
- Duarte Sousa — Analista e Arquiteto
- João Ferraz — Técnico
- Pedro Lopes — Secretário

## Estrutura
- `docs/` — website (publicado por GitHub Pages)
- `relatorios/` — relatórios e PDFs de planeamento
- `atas/` — atas de reunião
- `packet-tracer/` — ficheiros `.pkt` e configurações

## Aviso importante
Este repositório é **público**. Nunca colocar aqui palavras-passe, chaves (IPsec, RADIUS, PSK Wi-Fi), nem dados pessoais reais. Nos ficheiros `.pkt` e nas configurações usam-se apenas valores inventados de laboratório.
